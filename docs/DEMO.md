# 现场演示与提交准备

## 演示前

1. 提前编译服务端和 Android APK，确认 MATLAB 可用。避免在现场首次下载依赖。
2. 电脑、MATLAB 电脑和手机连接同一网络，电脑使用局域网启动参数。确认手机可访问服务端。
3. 在 App 中设好服务器地址、定位权限与起始原点。测试结束后关闭客户端和服务端，为正式启动做准备。
4. 检查无需网络 CDN 即可展示地图。确认现场浏览器支持 WebGL，2D 是兼容回退。
5. 关闭会影响测量的其他测试客户端，避免替换同类设备会话。

## 自主运行演示

MATLAB 已安装并加入 PATH 时，运行：

```powershell
.\scripts\start.ps1 -Lan -WithMatlab
```

手机端演示前配置完毕后连接，正式考核过程不再切换模式或遥控。观察：

- V01–V05 自动接单、上车、送达；完成数和总里程持续增长。
- M01 出现且真实 MATLAB 图窗中轨迹移动；其数字映像不是由服务端代走。
- 携带手机运动，P01 的 east/north/yaw 与帧数更新；手机实验区独立于城市道路。
- 静态建筑不被穿越，多车相遇时等待或绕行，碰撞计数为 0。

正式演示建议先持续两分钟不操作控制面板。策略切换、暂停、重置、断线恢复作为之后单独的功能说明；不要在自主运行片段中靠操作修复异常。

## 取证

网页右下角“导出本次运行数据”保存完整订单与状态；策略对比使用 experiments/ 中的 JSON 和汇总数据。运行截图应同时包含地图、车队状态、已完成订单和真实设备在线标记。视频建议：

1. 20 秒说明系统组成与自主启动。
2. 60 秒五车及 M01 接送、避让。
3. 40 秒手机传感器真实移动同步。
4. 40 秒同种子策略结果和局限。
5. 20 秒总结各成员实际贡献。

## 范围说明

PDF 建议从 Ridehail 演示改造，但它是参考路线而非课程对底层引擎的硬性限制。本工程参考其订单与车辆展示场景，自行实现 C++ 核心，以符合课件建议的 C++ 技术路线、方便无 Python 环境的现场运行，并避免引入大型 Python 仿真依赖。未将他人项目代码改名作为原创成果。

手机 P01 采用物理世界独立坐标系，不把室内手机位移强行吸附到城市出租车道路上。它在数字世界的独立实验区进行姿态/位置同步；若指导教师要求手机也必须参与同一城市网格调度，应在真实场地建立道路坐标标定后扩展，当前不宣称该扩展已完成。

正式展示还需要真实 MATLAB、Android 手机和网络环境，本地仿真验证不能替代这两项必做模块的真机验收。
